# ManageSMHL Frontend

## Environment

Create `frontend/.env` from `frontend/.env.example`.

- `VITE_API_BASE_URL`: API base URL used by fetch requests.
- `VITE_WS_URL`: realtime WebSocket URL.
- `VITE_API_PROXY_TARGET`: optional dev proxy target.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run lint`
